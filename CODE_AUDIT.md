# CODE_AUDIT — анализ качества кода OnlyGo

Метод: чтение кода всех модулей и фаззинг API скриптом. Скрипт шлёт около 200 запросов: пустые, emoji, 5000 символов, `<script>`, битый JSON, чужие id, двойную оплату, параллельные запросы. Каждая найденная ошибка закреплена тестом в `tests/test_quality.py`.

Проверено и в порядке: стыковки (прилёт → трансфер → заселение, выезд → вылет) не дают ложных ошибок. Метрики не ухудшились: completion 1.0, 0 ошибок стыковок, медиана ~6 мс. Секретов в репозитории нет, `.env` в `.gitignore`. CORS не включён: UI и API на одном origin, это безопаснее, чем `*`.
